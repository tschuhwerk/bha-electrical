⚙️  HOW TO USE DOCKER WITH YOUR WEBSITE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

OPTION 1: Docker Compose (Recommended) ⭐
──────────────────────────────────────────

Run this single command:
  docker-compose up --build

What it does:
  1. Builds Docker image from Dockerfile
  2. Creates a container
  3. Loads environment variables from .env
  4. Starts the website
  5. Shows live logs

Then visit: http://localhost:3000

To stop: Press Ctrl+C or type: docker-compose down


OPTION 2: Docker CLI (Advanced)
─────────────────────────────────

Run this command:
  docker run -d \
    --name bha-electrical-website \
    -p 3000:3000 \
    --env-file .env \
    --restart unless-stopped \
    bha-electrical:latest

Then visit: http://localhost:3000

To stop: docker stop bha-electrical-website

🔧 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Container won't start?
  → Check logs: docker-compose logs
  → Verify .env exists and has correct format
  → Check Docker daemon is running

Website shows blank page?
  → docker ps (verify container is running)
  → docker-compose logs (see error messages)
  → Clear browser cache: Ctrl+F5

Email not working?
  → Verify .env has all email settings
  → Check container logs for error messages
  → Restart: docker-compose restart

Port 3000 already in use?
  → Change port in docker-compose.yml
  → Or kill the process using that port
  → Try: lsof -i :3000
