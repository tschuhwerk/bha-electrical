METHOD 1: Docker Compose (RECOMMENDED) ⭐
───────────────────────────────────────────

docker-compose up --build

✓ Easiest to use
✓ Loads .env automatically
✓ One command to run everything
✓ Perfect for production
✓ Easy to manage

To stop: Press Ctrl+C or in another terminal: docker-compose down


METHOD 2: Docker CLI (Advanced)
─────────────────────────────────

docker run -d \
  --name bha-electrical-website \
  -p 3000:3000 \
  --env-file .env \
  --restart unless-stopped \
  bha-electrical:latest

✓ More control
✓ Manual management
✓ Good for scripting
✓ Useful for CI/CD

To stop: docker stop bha-electrical-website

🔧 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Container won't start?
  → docker-compose logs
  → Check .env file exists and has correct format

Website shows blank page?
  → Check if container is running: docker ps
  → View logs: docker-compose logs
  → Try clearing browser cache: Ctrl+F5

Email not working?
  → Verify .env has all email settings
  → Check container logs for error messages
  → Restart: docker-compose restart

Port already in use?
  → Check: lsof -i :3000
  → Find PID and kill it appropriately
  → Or use different port in docker-compose.yml

Need shell access?
  → docker exec -it bha-electrical-website sh
