     EMAIL_PASSWORD=your-16-char-password

   Option B: Other email services
   - Update EMAIL_SERVICE, EMAIL_USER, EMAIL_PASSWORD

3. START THE WEBSITE
   Terminal command:
   cd /home/tracy/IdeaProjects/Website
   npm start

   Visit: http://localhost:3000

================================================================================
                            HOW IT WORKS
================================================================================

USER FLOW:
1. Customer visits website at http://localhost:3000
2. Customer reads about services and company info
3. Customer scrolls to "Request Electrical Service" form
4. Customer fills out form with their request details
5. Customer clicks "Submit Service Request"

BACKEND FLOW:
1. JavaScript captures form data
2. Data is sent to /api/send-service-request endpoint
3. Server validates all required fields
4. Two emails are sent:
   - Email #1 to business with request details
   - Email #2 to customer with confirmation
5. User sees success message

================================================================================
                          EMAIL CONFIGURATION
================================================================================

For Gmail (Step-by-Step):

1. Enable 2-Step Verification:
   - Go to: https://myaccount.google.com/security
   - Look for "2-Step Verification"
   - Click and follow setup

2. Generate App Password:
   - Go to: https://myaccount.google.com/apppasswords
   - Select "Mail" and "Windows Computer"
   - Click "Generate"
   - Copy the 16 characters

3. Edit .env file:
   EMAIL_SERVICE=gmail
   EMAIL_USER=your-real-gmail@gmail.com
   EMAIL_PASSWORD=xxxx xxxx xxxx xxxx

4. Save and restart:
   npm start

================================================================================
                           DEPLOYMENT GUIDE
================================================================================

When ready to go live, you have several options:

HEROKU (Free tier available):
1. Create account at heroku.com
2. Install Heroku CLI
3. heroku create your-app-name
4. Set environment variables: heroku config:set EMAIL_USER=...
5. git push heroku main

VERCEL:
1. Create account at vercel.com
2. Connect GitHub repository
3. Add environment variables in Vercel dashboard
4. Deploy with one click

AWS / AZURE / DIGITAL OCEAN:
1. Choose hosting provider
2. Deploy Node.js application
3. Set environment variables
4. Map domain name
5. Set up SSL certificate

DOMAIN NAME:
1. Purchase domain (GoDaddy, Namecheap, etc.)
2. Point to your server's IP address
3. Update DNS records
4. Test website loads at your domain

================================================================================
                          IMPORTANT NOTES
================================================================================

⚠️  SECURITY
   - Never commit .env file to Git
   - Use app passwords, not real passwords
   - Keep email credentials private
   - HTML in form submissions is escaped to prevent attacks

⚠️  EMAIL LIMITS
   - Gmail: ~500 emails/day
   - Most providers have daily limits
   - Monitor email quota for high volume

⚠️  SPAM FOLDER
   - First emails might go to spam
   - Mark as "Not Spam" to improve delivery
   - Consider using dedicated email service

⚠️  CUSTOMIZATION
   - All contact info must be updated before going live
   - Test form submission before deploying
   - Verify emails arrive in inbox and spam folder
