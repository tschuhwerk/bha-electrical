GitHub requires authentication. Two methods:

METHOD 1: Personal Access Token (PAT) - RECOMMENDED ✅
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://github.com/settings/tokens
2. Click "Generate new token" → "Generate new token (classic)"
3. Give it a name (e.g., "Website Deploy")
4. Select scopes: ✓ repo (full control of private/public repos)
5. Click "Generate token"
6. Copy the token (looks like: ghp_xxxxxxxxxxxx...)
7. Run:
   
   git push -u origin main

8. When prompted:
   Username: tschuhwerk
   Password: [paste your PAT token here]

TOKEN WILL NOT ECHO - Just paste and press Enter!

METHOD 2: SSH Key Setup (One-time setup, then no password needed)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Check if SSH key exists:
   ls -la ~/.ssh/id_rsa

2. If not, create one:
   ssh-keygen -t rsa -b 4096 -f ~/.ssh/id_rsa -N ""

3. Copy public key:
   cat ~/.ssh/id_rsa.pub

4. Go to: https://github.com/settings/keys
5. Click "New SSH key"
6. Paste your public key
7. Change git remote to SSH:
   
   git remote set-url origin git@github.com:tschuhwerk/bha-electrical.git

8. Then push:
   git push -u origin main
