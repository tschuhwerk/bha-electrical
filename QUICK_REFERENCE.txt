🐛 TROUBLESHOOTING

   Website won't start?
   → npm install
   → npm start

   Form not sending?
   → Check .env file is configured
   → Look at terminal for error messages
   → Enable 2FA for Gmail if using it

   Emails not arriving?
   → Check spam folder
   → Verify BUSINESS_EMAIL in .env
   → Look for errors in server terminal
